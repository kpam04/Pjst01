# 🐾 Pet Lover Web

เว็บไซต์แนะนำและให้ข้อมูลเกี่ยวกับสัตว์เลี้ยง สร้างด้วย HTML และ CSS ล้วน เหมาะสำหรับผู้ที่กำลังตัดสินใจเลี้ยงสัตว์และต้องการข้อมูลพื้นฐานของสัตว์เลี้ยงยอดนิยมแต่ละชนิด

## 📖 เกี่ยวกับโปรเจกต์

Pet Lover Web รวบรวมข้อมูลสัตว์เลี้ยงยอดนิยม พร้อมข้อดี-ข้อควรระวังในการเลี้ยงสัตว์ เพื่อช่วยให้ผู้ใช้งานตัดสินใจเลือกสัตว์เลี้ยงที่เหมาะกับตัวเองได้ง่ายขึ้น

## ✨ ฟีเจอร์

- หน้าแรกแนะนำเว็บไซต์ พร้อมปุ่มเริ่มต้นสำรวจ
- หน้า "ควรเลี้ยงสัตว์หรือไม่" สรุปข้อดี/ข้อควรระวังของการเลี้ยงสัตว์
- หน้ารวมประเภทสัตว์เลี้ยง
- หน้าข้อมูลเฉพาะสายพันธุ์: สุนัข แมว กระต่าย และแฮมสเตอร์
- หน้าติดต่อเรา

## 🗂️ โครงสร้างไฟล์

```
Pjst01-main/
├── Home.html              # หน้าแรก
├── About.html             # ควรเลี้ยงสัตว์หรือไม่
├── Animal.html            # ประเภทสัตว์เลี้ยง
├── Dog.html                # ข้อมูลสายพันธุ์สุนัข
├── Cat.html                # ข้อมูลสายพันธุ์แมว
├── Rabbit.html              # ข้อมูลสายพันธุ์กระต่าย
├── Hamster.html             # ข้อมูลสายพันธุ์แฮมสเตอร์
├── Contact.html             # ติดต่อเรา
├── style1.css               # สไตล์หน้า Home
├── style2.css                # สไตล์หน้า About
├── style3.css                 # สไตล์หน้า Animal
├── style4.css                  # สไตล์หน้าสายพันธุ์สัตว์ (Dog/Cat/Rabbit/Hamster)
├── style5.css                   # สไตล์หน้า Contact
├── Pet Lover web logo.png        # โลโก้เว็บไซต์
└── Sitemap                        # แผนผังเว็บไซต์
```

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5** สำหรับโครงสร้างเนื้อหา
- **CSS3** สำหรับการจัดรูปแบบและดีไซน์ (แยกไฟล์ตามแต่ละหน้า)

## 🚀 วิธีใช้งาน

โปรเจกต์นี้เป็นเว็บไซต์แบบ static ไม่ต้องติดตั้ง dependency ใด ๆ

1. Clone repository นี้
   ```bash
   git clone https://github.com/kpam04/Pjst01.git
   ```
2. เปิดไฟล์ `Home.html` ด้วยเว็บเบราว์เซอร์ เพื่อเริ่มใช้งาน
